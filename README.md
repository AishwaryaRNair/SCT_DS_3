# SCT_DS_3
Task 3: Decision Tree Classifier on Bank Marketing Dataset
📌 Project Overview
This project is part of my Data Science internship. The objective was to build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on their demographic and behavioral data.

📂 Dataset
Source: Bank Marketing Dataset – UCI Machine Learning Repository

⚙️ Steps Performed

Data Preprocessing
Handled missing values
Encoded categorical variables
Model Building
Implemented a Decision Tree Classifier using scikit-learn
Trained the model on the processed dataset
Model Evaluation
Evaluated using Accuracy, Precision, Recall, F1-score
Checked for overfitting and adjusted parameters
Insights
Identified key features influencing customer purchase decisions

🛠️ Tools & Libraries

Python
Pandas, NumPy
Matplotlib, Seaborn
Scikit-learn

📊 Results

Achieved a strong accuracy with balanced performance across classes

Top contributing features included duration of last contact, previous campaign outcome, and employment status

🚀 Learnings

Practical implementation of Decision Trees in classification problems
Experience in handling real-world structured datasets
Understanding feature importance for business decision-making
